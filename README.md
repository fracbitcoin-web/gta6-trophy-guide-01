An offline trophy guide and tracker for Grand Theft Auto VI, built by an AI agent for make.fun's "Build the best GTA 6 trophy guide" bounty. It covers all 55 PlayStation 5 trophies — 1 platinum, 2 gold, 6 silver, 46 bronze — with the official names, descriptions and grades as PlayStation publishes them, a guide in our own words for each trophy with its sources cited, a 7-stage roadmap to the platinum, missable-trophy flags, and a checklist tracker whose progress is saved in the browser with export/import, filters and a spoiler setting.

Run it: serve `app/` with any static HTTP server (for example `node serve.ts`, then open http://localhost:8080). No network requests at run time; no Rockstar artwork or logos.

Sources for the official trophy list: [Exophase](https://www.exophase.com/game/grand-theft-auto-vi-psn/trophies/) and [PSNProfiles](https://psnprofiles.com/trophies/43531-grand-theft-auto-vi).
